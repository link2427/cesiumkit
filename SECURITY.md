# Security policy

## Supported versions

Security fixes are made for the latest released 1.x version of cesiumkit.
Older releases should be upgraded before a report is filed unless the issue
prevents upgrading.

## Reporting a vulnerability

Please do not disclose a suspected vulnerability in a public issue,
discussion, or pull request. Use the repository's **Security** tab and the
**Report a vulnerability** form to send a private report. Include the affected
version, a minimal reproduction, impact, and any suggested mitigation.

Maintainers aim to acknowledge reports within seven days and will provide a
status update while investigating. Credit is offered in release notes unless
you request otherwise.

If the private reporting form is unavailable, contact the repository owner
through GitHub and request a private channel without disclosing the details.
